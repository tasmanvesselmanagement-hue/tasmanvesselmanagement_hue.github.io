## Local Development
If you need to view or edit the site locally, the process is straightforward since it relies on static HTML:
1. Clone or download this repository.
2. Open the `index.html` file directly in any modern web browser (e.g., Chrome, Edge, Safari).
3. Make your desired edits using a text editor or by consulting an AI assistant like Claude. 
4. Commit and push the changes back to the `main` branch to automatically update the live site via GitHub Pages.
